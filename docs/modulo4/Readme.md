## 🎯 Objetivo

Diseñar y evaluar una celda robotizada que sustituya el paletizado manual, mejorando la **productividad, repetibilidad, ergonomía y seguridad** del proceso.

## 🏭 Solución propuesta

La celda utiliza un robot **ABB IRB460-110/2.40** e integra el manejo de packs, dispensación de pallets, separadores, supervisión operativa y elementos de seguridad industrial.
